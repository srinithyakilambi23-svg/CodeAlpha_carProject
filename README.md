# Car Price Prediction using Machine Learning

## Overview
This project predicts the selling price of cars using machine learning regression techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Features
- Data preprocessing
- Feature engineering
- Linear Regression model
- Model evaluation
- Data visualization

## Machine Learning Workflow
1. Load dataset
2. Clean and preprocess data
3. Encode categorical values
4. Train regression model
5. Predict car prices
6. Evaluate performance

## Dataset
Car dataset containing:
- Present Price
- Kilometers Driven
- Fuel Type
- Transmission
- Owner
- Selling Price

## Results
The model predicts car selling prices with good accuracy using regression techniques.
